# Pinned contract bundle

This directory contains a byte-pinned copy of the
`hermes-rewrite-contract/v1` fixtures generated by the Python reference oracle.

`SOURCE.json` records the source revision, draft state, and exact SHA-256 of
every fixture. Rust tests consume these goldens directly and never invoke
Python. The source corpus was uncommitted at the pinned base revision, so the
manifest labels that state explicitly rather than implying the Git revision
alone contains these bytes.
